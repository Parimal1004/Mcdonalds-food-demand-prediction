McDonald's Food Demand Prediction

📌 Project Overview

This project predicts McDonald's food sales/demand using machine learning.

The project uses a synthetic academic dataset and focuses on data preprocessing, exploratory sales analysis, Random Forest regression, and evaluation of predicted demand.

Note: This project does not use McDonald's real internal or proprietary data.

🎯 Objective

The main objective is to build a machine learning model that can predict Sales based on factors related to previous sales, customer count, promotions, weekends, and food category.

The project workflow is:

Raw Data → Data Cleaning → Feature Selection → Exploratory Analysis → Random Forest Regression → Sales Prediction → Model Evaluation

📊 Dataset

The notebook is designed to work with a synthetic dataset named:

mcdonalds_food_demand_raw_3000.csv

The raw dataset contains approximately 3,035 rows before preprocessing.

The project checks and handles common data-quality issues such as:

Duplicate records

Missing values

Inconsistent categorical values

Invalid negative numeric values

Sales outliers

🔑 Main Features

The model uses the following five features:

Feature

Description

Previous_Day_Sales

Sales from the previous day

Customers

Number of customers

Promotion

Indicates whether a promotion was active

Is_Weekend

Indicates whether the day was a weekend

Food_Category

Category of food being considered

Target Variable

Sales

The target represents the sales value that the model attempts to predict.

🧹 Data Preprocessing

The notebook performs the following preprocessing steps:

Remove duplicate records

Standardize categorical values

Removes extra spaces

Standardizes capitalization

Convert data types

Dates are converted to datetime

Numeric columns are converted to numeric types

Handle invalid values

Negative customer counts and prices are treated as missing

Handle missing values

Categorical values are filled using the mode

Numerical feature values are filled using the median

Rows with missing target (Sales) values are removed

Handle sales outliers

Uses the IQR (Interquartile Range) method

Feature selection

Label encoding

Food_Category is converted into numerical values

The final encoded feature set is:

Previous_Day_Sales, Customers, Promotion, Is_Weekend, Food_Category_enc

📈 Exploratory Data Analysis

The project analyzes sales trends using:

Average Sales per Day

Average Sales per Month

These visualizations help identify changes and patterns in sales over time.

🤖 Machine Learning Model

Random Forest Regression

The project uses a Random Forest Regressor because Sales is a continuous numerical target.

The model is configured with:

200 decision trees

random_state = 42

No maximum tree depth specified

min_samples_split = 2

The dataset is divided into:

80% Training Data

20% Testing Data

📏 Model Evaluation

The Random Forest model is evaluated using:

MAE — Mean Absolute Error

Measures the average absolute difference between actual and predicted sales.

RMSE — Root Mean Squared Error

Measures prediction error while giving greater weight to larger errors.

R² — R-squared

Measures how well the model explains the variation in the target variable.

Additional evaluation and visualization include:

Actual vs Predicted Sales

Actual vs Predicted Sales scatter plot

Demand-category Confusion Matrix

Random Forest Feature Importance

The confusion matrix is an additional analysis. The main model is a regression model, so MAE, RMSE, and R² are the primary evaluation metrics.

📊 Demand Category Analysis

For additional analysis, continuous sales predictions are converted into three demand categories:

Low Demand

Medium Demand

High Demand

A confusion matrix is then used to compare the actual and predicted demand categories.

⭐ Feature Importance

Random Forest feature importance is used to identify which features contribute most to the model's predictions.

The importance is calculated using the trained Random Forest model's feature_importances_ values.
