## 📌 Project Overview

This project focuses on predicting **McDonald's food sales/demand** using machine learning.

The project uses a **academic dataset** from kaggle and demonstrates the complete machine learning workflow, including:

- 🧹 Data preprocessing
- 🔍 Exploratory data analysis
- 🎯 Feature selection
- 🌲 Random Forest Regression
- 📈 Sales prediction
- 📏 Model evaluation
- ⭐ Feature importance analysis
- 📊 Demand-category analysis


---

## 🎯 Objective

The main objective is to build a machine learning model that predicts **Sales** based on factors related to:

- Previous sales
- Customer count
- Promotions
- Weekends
- Food category
